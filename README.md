# Sal-n-De-Juegos-U.M.N.G
El proyecto "Salón de Juegos U.M.N.G" es una consola de entretenimiento interactiva programada en MicroPython. A través de una pantalla OLED, luces LED, botones y sensores, permite disfrutar de divertidos minijuegos de carreras, reflejos y tiro. Es un sistema electrónico que integra WiFi, combinando el desarrollo técnico con pura diversión.
